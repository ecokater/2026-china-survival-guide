# 第三篇：社保改动——晚退、多缴、分而治之

> 提问：结合一下中国最近的社保改动分析一下
>
> TL;DR：核心结论：延迟退休（男63/女55/58）+ 缴费年限 15→20 年 + 社保强征三重紧缩；放法国是全国瘫痪、放俄罗斯是总统道歉，在中国变为年轻人对代际契约的无声撕毁。

---

把社保改动加进来，整个图景就完整了，而且更锋利了。

因为**养老金改革是全球公认的政治炸药包**。如果说GDP注水、失业率还是“感受问题”，社保是直接从每个人工资条里扣钱、晚5年才能领的“抢钱问题”。在其他国家，这就是改朝换代级别的导火索。

而中国在2024-2025年，恰恰在真实经济最差的时候，干了三件其他国家都不敢同时干的事：**晚退 + 强征 + 预期少领。**

### 1. 最近到底改了什么？不是小修小补，是1949年以来最大的一次

**（1）延迟退休：2024年9月通过，2025年1月1日执行**
男60→63岁，女工人50→55岁，女干部55→58岁，15年渐进式。同时把最低缴费年限从15年提到20年（2030-2039年渐进）。

这是1950年代确立退休制度以来第一次动年龄。上次一提要延退，舆论就炸了10年，这次直接通过。

**（2）社保强征：2025年9月1日起，来真格的了**
《社会保险法》2011年就说必须交，但10多年执行都是睁只眼闭只眼，大量中小企业按最低基数交、甚至签协议不交、发补贴让员工自己看着办。

两件事终结了灰色地带：
* 税务征缴 + 金税四期联网：工资、个税、社保三数比对，不交的一眼看到
* 最高法2025年8月司法解释（二）：明确任何“自愿放弃社保”的协议一律无效，员工可以此为由辞职并要求企业付经济补偿金，9月1日施行

意味着：以前是“可以不交”，现在是“不交违法且员工随时可以告你”。

**（3）个人养老金全国推开：2024年12月**
2022年36城试点，每年12000额度，税前抵扣，全国推开。但开户7000多万人，实际缴钱的不到15%。年轻人用脚投票：不信。

**（4）医保先动刀，已经爆过一次**
2023年职工医保门诊共济改革：个人账户划入大幅减少（退休老人每月少几百），统筹报销增加。结果直接引发**2023年2月武汉、大连“白发运动”**：几千名退休老人堵市政府、中山公园聚集抗议。这是白纸运动之后最大规模的群体性事件。

城乡居民医保更惨：个人缴费从2003年的10元/年涨到2024年的380元/年，2025年继续涨，农村出现大面积断缴，参保人数连续下降。

**（5）城乡居民养老金：象征性涨20块**
2024年政府工作报告：基础养老金月最低标准提高20元，从103元涨到123元。2025年再涨20元到143元。

143元 vs 机关事业单位退休6000-8000元，企业职工3000元左右。这就是中国的三轨制：同一片土地，养老金差40倍。

### 2. 为什么偏偏在经济最差的时候收紧？因为基金真的要穿底了

这不是改革，是救火。

根据社科院郑秉文团队2019年那份著名的精算报告（《中国养老金精算报告2019-2050》）：在不改革、保持5%左右工资增长的假设下，城镇职工养老金累计结余将在2035年耗尽。

但那个假设现在看 optimistic 得可笑：
* 假设工资每年涨5%，真实名义增速现在是0-2%
* 假设生育率回升，实际是人口2022年起连续负增长，60岁以上已经超3亿，占比21%+
* 假设没有地产危机，实际是地方财政补贴养老金的能力被土地财政崩盘掏空了

现实是：2023-2024年已经有11个省份当期收不抵支，东北、青海、内蒙早穿底了，全靠广东、北京、江苏等7个省结余 + 中央每年2800多亿调剂 + 财政1万多亿补贴撑着。

IMF 2023年第四条款磋商直接点名：中国养老金缺口叠加地方隐性债（LGevydFy城投60万亿+），是中期最大财政风险。

所以逻辑链很清楚：
**真实增速只有1-2%（上次说的挤水分后）→ 工资不涨、年轻人断缴 → 收的少了 → 老人越来越多、领的多了 → 地方政府没钱补了 → 中央只能：让大家晚领（延退）+ 多交（强征）+ 自己存（个养金）。**

延迟退休只能买5-7年时间。这是精算界的共识。下一步必然是降替代率（同样交钱，领的更少）或者涨费率，现在企业+个人养老+医疗+失业+工伤+生育加起来已经是工资的35-40%，中小企业根本扛不住。

### 3. 在当前真实经济下，这套组合拳意味着什么？顺周期紧缩

如果经济真的是5%高增长，社保改革是“未雨绸缪”。但如果真实是1-2% + 通缩 + 青年失业30%，这就是**在病人发烧时抽血**：

**对企业：成本突然涨20-30%**
一个在东莞、义乌的厂，原来按最低基数给100人交社保，一个月多掏5-8万。9月1日后按实际工资全额交，一个月多掏20-30万。在PPI通缩、订单下滑、利润为负的时候，这就是压垮骆驼的最后一根稻草。

结果只有三个：裁员、降底薪对冲社保涨幅、关厂转外包。越强制，正规就业越贵，年轻人越被赶到灵活就业和外包里去，税基反而缩小。经济学上典型的拉弗曲线。

**对年轻人：实际降薪 + 世代违约**
95后、00后算得很精：我现在每月多扣500-800，63岁才能领，领的时候替代率可能从现在的45%降到30%，还要养4个老人+还房贷。这回报率还不如自己存银行。

所以知乎、B站上“社保庞氏”、“断缴攻略”大行其道。强制后不能不交，就想办法按最低基数交。信任已经没了。

**对消费：雪上加霜**
社保改革的长期目标是对的：让大家老有所养，就不敢存那么多钱，敢消费。但短期是反的：从可支配收入里多扣钱，在通缩环境下直接减少消费。2024-2025年社零本来就只有2-3%真实增长，这下又被抽走一块。

这就是为什么经济学家骂：**用长期正确的改革，加剧了短期衰退。**

### 4. 放到其他国家，这是什么量级？法国和俄罗斯已经演示过了

养老金是政治学里著名的“Blame Avoidance”（避责政治，Pierson 1994《福利国家的新政治》）：选民对“失去既得福利”的愤怒，是对“没得到新福利”的3-5倍（损失厌恶）。所以所有政府都知道：动养老金，就是找死。

**法国2023：只动了一项，就全国瘫痪**
马克龙把退休年龄62→64岁，当时法国增长1%左右，青年失业17%，通胀但没通缩。结果：1200万人次上街，炼油厂、铁路、学校、垃圾清运全国罢工3个月，巴黎垃圾堆成山，议会差点被不信任投票推翻，马克龙动用宪法49.3强行通过，支持率崩盘。

法国人只晚退2年就这样，中国是晚退3-5年 + 缴费年限15→20年 + 强征。

**俄罗斯2018：普京执政最大滑铁卢**
普京把男60→65，女55→60，当时俄罗斯增长2%左右，有石油钱，青年失业不到15%。结果：普京支持率从82%一个月跌到64%，统一俄罗斯党在远东、伏尔加地方选举惨败，全国几十城游行。普京被迫亲自电视讲话道歉，把女性年龄从63回调到60。这被公认是他2012年回任后最大的国内危机。

俄罗斯的经济状况比现在中国真实状况还好，改革力度比中国还小，尚且如此。

**希腊2010-2012：直接换政权**
主权债务危机后被迫砍养老金30-40%，结果是：宪法广场骚乱、5年换5届政府、极左Syriza上台、极右金色黎明进议会。

**中国2024-2025：三项全动 + 真实经济更差，却零街头运动。** 除了2023年武汉老人那一次，年轻人、企业主几乎是沉默接受。这就是中国模式最让比较政治学家困惑的地方。

### 5. 为什么中国没爆？因为把“一颗大炸弹”拆成了“一万颗小鞭炮”

不是中国人不痛，是痛感传导机制被精心设计过了：

1.  **碎步 + 渐进 + 算不清：** 15年渐进，每年多干2-4个月，你算不清自己到底亏了多少。没有一个像法国那样的“62→64”的清晰投票日，没有组织动员的焦点。
2.  **利益高度分裂，无法结盟：** 机关老人领8000，觉得改革与我无关；企业职工领3000，骂但不敢动；农民领143元，觉得涨20也是涨；年轻人觉得反正我也领不到，躺平算了。四拨人互相羡慕嫉妒，形不成统一战线。这是三轨制最大的政治功能：分而治之。
3.  **没有组织者：** 法国有总工会CGT，俄罗斯还有共产党和纳瓦尔尼。中国独立工会、反对党、教会、NGO一个都没有。企业主想集体抗议税负？第一时间就被约谈。年轻人想串联？群就没了。
4.  ** pick 软柿子：** 政府学精了。2023年切退休老人的医保，老人们是真敢上街（武汉），因为他们有时间、有组织、有体制内人脉，政府马上软化，加大统筹报销安抚。而切年轻人和中小企业的，知道他们不敢、不愿、没时间上街，就往死里切。

这就是 Pierson 说的 retrenchment（福利收缩）最成功的策略：** blame diffusion（责任扩散）+ division（分裂）+ delay（延迟痛感）。** 中国把它做到了极致。

### 结论：真正的风险不是上街，是“无声违约”

把社保加进来后，之前的判断要修正得更严峻一点：

用真实数据（1-2%增长 + 30%青年失业 + 通缩）+ 社保三重紧缩（晚退、多缴、少领预期），放在法国是全国瘫痪，放在俄罗斯是总统道歉，放在希腊是政府倒台，放在埃及是革命。

在中国，它转化成了一种更难治理的东西：**年轻人对代际契约的单方面撕毁。**

不游行，不抗议，但：
* 能按最低基数绝不按实际
* 能不结婚不生娃就不生（反正养不起老+养不起小）
* 能考公躺平绝不创业消费
* 结婚率历史最低、生育率全球最低、个人养老金没人交

这是一种没有谈判对象的抵抗。政府可以镇压游行，但没法镇压“不生孩子、不消费、不信任”。养老金数学在1-2%的真实增速下是算不过来的，延迟退休买来的5年，很快就会被更低的生育率和更低的参保意愿吃掉。

社保改革保住了基金5年，却透支了年轻人30年的信任。这笔账，可能是2026年中国经济所有账里最贵的一笔。

要不要我帮你算一笔具体的账？比如：**一个2025年毕业、月薪8000的普通本科生，按新规一生要多交多少、晚领多少、实际回报率是多少？** 算完你就知道为什么年轻人是这个态度了。
