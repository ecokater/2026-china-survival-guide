# 第七篇：中国普通人的财产与投资策略

> 提问：根据以上所有信息，你分析一下作为一个中国普通人应该做的投资策略或者财产策略。
>
> TL;DR：核心结论：未来 10 年不是谁赚得多，是谁亏得少、谁留着选择权。现金为王→降杠杆→小步定投→合规出海；房子少一套焦虑少一半，杠杆降一分睡眠好一分。非投资建议。

---

前面四篇是"诊断"，这一篇是"开方"。但开方之前必须先说三句丑话：

1. **我不是持牌投资顾问，这篇是基于宏观分析的讨论，不是投资建议。** 大钱决策请咨询持牌专业人士。
2. **不荐股、不荐基、不荐具体产品**，只讲资产类别和配置逻辑。凡是点名让你买某只的（包括我），都该拉黑。
3. **投资策略是前面所有分析的函数**——如果你不认同"真实增速1-2%+通缩+连任+管制收紧"这组判断，后面的结论都要打折。先对齐诊断，再抄作业。

对齐完，开始。

### 1. 先把大判断翻译成6条"投资公理"

前面四篇的结论，翻译成投资者语言就是：

| 宏观判断 | 投资含义 |
|---|---|
| 真实增速1-2% + 通缩 | 名义回报全面下移，"年化8%"的时代结束了，能跑赢通缩（约-1~0%）就是胜利 |
| 利率长期下行（存款破1%） | 安全资产回报归零，日本化：活着的钱越来越不值钱，但冒险的钱死得更快 |
| 房地产去金融属性 | 房子从"资产"变"消费品/负债"，出租回报1-2%、下跌风险20-40%，数学上没法看 |
| 人民币贬值压力 + 资本管制收紧 | 美元资产是硬通货，但钱出去越来越难，"出海"窗口只会越收越窄 |
| 2027大概率连任、政策连续 | "安全>效率、国进民退、产业政策"延续5-10年，结构性机会只在"国家要干的方向" |
| 尾部风险（台海、脱钩、房产税/遗产税立法预期） | 肥羊风险真实存在，鸡蛋不能放在一个篮子里，更不能放在一只羊身上 |

记住这6条，后面所有具体建议都是它们推导出来的。任何时候拿不准，就回来查表。

### 2. 总纲：三句话，背下来

**第一句：保住现金流 > 追求回报。**

通缩+下行周期里，投资赚的那3-5个点，远不如"不断供、不失业、不垫底"重要。日本"失去三十年"最大的赢家画像不是股神，是：**有稳定工作、没房贷、存现金、不离婚的中产。** 听起来像笑话，数据上是真的——日经用了34年（1989-2024）才创新高，这34年里任何折腾跑赢"存银行+上班"的散户都寥寥无几。

**第二句：降杠杆 > 加杠杆。**

上行周期，杠杆是放大器；下行周期，杠杆是绞肉机。中国居民杠杆（房贷为主）63%，已经是发展中国家最高一档。通缩环境下债务的实际负担每年自动加重（欠的钱不变，收入和资产在缩水）——经济学上叫"债务-通缩螺旋"（Fisher 1933，辜朝明整套理论的老祖宗）。**这个阶段任何加杠杆的行为（加仓、买二套、抵押经营贷炒股），都是和宏观规律对赌。**

**第三句：分散 + 流动性 > 集中 + 长期锁定。**

政策变得比天气快（教培一夜团灭、清零一夜放开），地缘黑天鹅随时飞（台海、关税、SWIFT）。**ruch任何3年内拿不回来的钱，都要问一句：如果明年政策180度掉头/后年打仗/大后年换汇彻底锁死，这笔钱怎么办？** 答不上来就别投。

### 3. 分资产讲：每一类怎么处理

**（1）房子：从"信仰"降级为"消费品"，多余的都是负债**

* **自住一套**：刚需自住不讨论涨跌，住得舒服、月供低于家庭收入40%就行。但二套以上、远郊、旅游地产、县城商铺——每一套都在问三个问题：租售比多少？（低于2%就是负资产预备役）3年后好卖吗？（三四线现在就是有价无市）持有成本多少？（物业+折旧+资金占用）。
* **提前还贷算账**：房贷利率4%+，理财回报2%，存款1%——提前还贷=锁定4%的无风险收益，数学上是最优的"投资"。唯一的例外：你有确定年化>4%的投资渠道（99%的人没有），或者你是经营贷3%以下的便宜钱。
* **分化警告**：日本经验——东京核心区30年后创新高，地方城市跌80%再也没回来。中国也一样：**一线核心区 vs 三四线，是两种资产。** 别拿"北上深永远涨"安慰自己手里的鹤岗/燕郊/惠州。
* **红线**：法拍房数量2024-2025年历史新高，断供=征信死刑+首付打水漂。月供压力大的，卖房止损永远优于断供。

**（2）现金/存款/国债：压舱石，比例要比你想象的高**

* **6-12个月家庭开支的活钱**（货币基金/活期），雷打不动。这是失业、断供、生病的救命钱，不是"低收益的浪费"。
* **大额存单/国债**：利率还在下行通道（预定利率、存款利率只会越来越低），长期限的可以锁定一部分。但别All in 5年期——流动性条款看清楚，提前支取怎么算。
* **心态校准**：存款1%看起来像笑话，但在-1%通缩+房价-5%+股市-10%的环境里，**1%的存款=实际2%+相对20%的胜利**。通缩时代，不亏就是赚。

**（3）A股：可以玩，别梭哈，仓位决定命运**

* **总量判断**：政策市+散户市+经济下行，指数级牛市没有土壤。结构性机会永远有（国企红利、产业政策链条），但属于专业选手。
* **普通人姿势**：宽基指数定投 + 红利类资产，仓位上限建议不超过可投资资产的20-30%（年轻人可高一点，40岁以上往下调）。定投是为了"跌了敢买、涨了不追"，不是为了发财。
* **韭菜税清单**：题材炒作、打新神话、加杠杆（融资融券/场外配资）、听消息、频繁交易。A股70%散户亏损不是段子，是中登数据。
* **港股**：同一批资产更便宜的版本（AH溢价常年30%+），分红率更高，适合红利策略。但流动性和退市风险要懂，别碰仙股。

**（4）美元和出海：最重要，也最难**

* **逻辑**：人民币中长期贬值压力（利差、中美脱钩、央行放水空间）vs 你的资产100%是人民币——这本身就是最大的集中度风险。对冲它的唯一办法是美元资产。
* **合规渠道**（按门槛从低到高）：①外币存款（四大行直接换，利率4%+，但额度内）；②QDII基金（买美股/全球指数，额度紧张、经常限购，早开户早上车）；③香港保险（增额寿/年金，美元计价，锁定长期利率——但738、换汇、理赔地、政策变动风险都要研究透，别听中介忽悠）；④海外券商（人在境外/有境外卡才合规，-pay attention 两地税务）。
* **每年5万美元额度**：合法的就用足，但**"蚂蚁搬家"（借用亲友额度）是违法的**，外汇局2024-2025年罚单越开越多。地下钱庄=刑法，碰都别碰。
* **现实**：普通人能换出去的就是一年5万，10年50万。对中产家庭，这是"诺亚方舟船票"，优先给子女教育和养老，不是一夜暴富工具。

**（5）黄金：乱世对冲，小仓位**

* 5-10%仓位，金条/黄金ETF/积存金都行，别碰纸黄金杠杆和来路不明的"现货"。
* 逻辑：对冲尾部风险（战争、恶性政策、货币信用），不是为了赚钱。涨了别追，跌了定投一点。

**（6）信托/私募/币/资金盘：高危区，默认别碰**

* 中植系2023年暴雷（自融+地产，坑的是高净值）、恒大财富、P2P全灭——**"刚兑信仰"已死，任何承诺8%+的都要问：钱去哪了？抵押物是什么？暴雷了我排第几顺位？**
* 币圈：政策上随时可以定性非法，价格上90%的人亏钱。和"分散风险"的目标背道而驰——它和你的A股、房子在危机时一起跌，分散了个寂寞。
* 一句话：**看不懂的+高收益的+亲戚推荐的=三杀，跑。**

**（7）社保：把它当税，不当投资**

* 体制内/大厂打工人：没得选，足额交，认了。
* 灵活就业/小老板：算账——按最低基数交满15年（未来20年）拿个"入场券"，多交的部分回报率极低（上一章算过：替代率从45%往30%去，63岁领，能活多久？）。**省下来的钱自己存，比交给池子强。** 但注意合规：2025年9月强征后，有雇员的企业不交=违法，罚金+补偿金更贵。
* 医保别断：居民医保380/年，买的是"大病不返贫"，杠杆最高的一笔钱。

**（8）保险：只买保障型，理财型当工具用**

* 重疾+医疗+意外+寿险（有房贷/小孩的）：必须消费，占家庭年收入5-8%封顶。这是"防止 Matplotlib 式人生断崖"的唯一工具。
* 增额终身寿/年金：本质是"锁定长期利率"的工具。预定利率从3.5%→3.0%→2.5%一路下调（还会调），有长期锁定需求的早研究早决定。但记住：**锁死20年的钱，买之前先过"第三句"（流动性测试）。**

**（9）最大的一笔"投资"：人生决策**

* **考公考研考编**：在"体制内外收入差+社保双轨制"下，考公=买了一份"旱涝保收+高替代率养老"的年金。别笑，这是2026年中国回报率最高的"投资"之一。代价是35岁门槛和 creativity 死亡，自己权衡。
* **结婚买房时机**：房价下行期，晚买=省钱。"丈母娘刚需"正在被现实教育——2024-2025结婚率历史新低，说明年轻人已经在用脚投票。感情归感情，首付归首付。
* **润**：成本最高、收益最不确定的"投资"。技术移民/留学/工作签是正道，偷渡和黑下来是拿命赌。有语言+技能+存款的可以认真规划，三无的先在国内把前两项搞定。**润出去送外卖 vs 在国内送外卖，数学上不一定划算，尊严上另算。**

### 4. 分人群组合：对号入座

| 人群 | 目标 | 配置思路 | 红线 |
|---|---|---|---|
| 年轻人/月光族 | 别负债，攒第一桶金 | 6个月活钱→定投宽基（小额）→考证/技能；社保按最低交 | 别碰网贷/花呗分期/币；别为面子消费 |
| 新中产房贷家庭 | 不断供，降杠杆 | 提前还贷优先→活钱12个月→20%权益定投+美元+黄金小仓位→保障型保险配齐 | 别买二套；别辞职创业All in；别给亲戚担保 |
| 小企业主 | 活下去，别被社保/税压垮 | 现金为王（18个月）→合规化（社保/税，一个罚单顶一年利润）→不扩张、砍亏损业务→家庭和企业账分开 | 别抵押房子救公司（救活概率<10%，房子没了概率100%）；别民间借贷 |
| 高净值/可转移者 | 分散+合规出海 | 全球配置（美元/美股/港险）→国内只留自住+经营必需→研究税务居民身份和遗产安排 | 别信地下钱庄；别All in信托/私募；关注房产税/遗产税立法动向 |
| 体制内临退休 | 落袋为安 | 存款+国债+增额寿锁定→医保别断→帮子女首付量力而行（别掏空养老钱） | 别碰"高息理财"/收藏品/保健品；别给子女全款买二套 |

### 5. 负面清单：这5件事，一件都别干

1. **别加杠杆**：抵押经营贷炒股/买房、融资融券、信用卡套现投资——下行周期杠杆=自杀，还连累家人。
2. **别信高息**：8%以上的"固定收益"，不是骗子就是赌徒。你的本金是别人的收益。
3. **别碰法律红线**：地下钱庄、蚂蚁搬家超额换汇、代持、洗钱——以前睁只眼闭只眼，现在金税四期+反洗钱，大数据比你记得清。
4. **别All in任何单一资产**：房子、股票、存款、甚至美元——All in的本质是拒绝承认自己看不懂未来。而未来5年，没人看得懂。
5. **别忽视流动性**：5年期、10年期的封闭产品，买之前做"压力测试"：失业+断供+父母大病同时发生，这笔钱能救命吗？不能就减半。

### 6. 日本对照：失去三十年，普通人怎么做对/做错的

最后回到中日对比，给三个日本普通人的真实结局：

* **做对的**：1990年没买房、存银行+买国债的上班族——30年存款利息+本金安然无恙，2003年 uplifting 日经7607点位买点指数基金，现在财务自由。核心策略就四个字：**现金为王**。
* **做错的**：1990年高位接盘东京郊区房+贷款30年——房子跌60%，月供一分不少，还了30年发现房子还欠银行钱。对应中国现在的三四线+远郊接盘侠。
* **分化的**：东京山手线内核心区，30年后创新高；地方城市，跌80%永不回来。对应中国：**核心城市核心区可能是"跌出来的机会"（2030年后看），三四线可能是"永远的坑"。** 别混为一谈。

日本还有个被忽视的赢家群体：**早年买了美股/美元资产的人**。1990年1美元=160日元，2011年75日元，2024年150日元——汇率波动巨大，但美股30年涨了10倍。配置了海外资产的日本家庭，基本对冲了国内的失去。这就是"美元/出海"那一节的逻辑来源。

### 7. 每年体检一次：动态再平衡的5个信号灯

策略不是一成不变的，每年看一次这5个灯，变了就调仓：

1. 🟢/🔴 **二十一人事（2027）**：连任+改革派冒头=加仓中国资产信号；连任+ further 集权=维持防守。
2. 🟢/🔴 **房地产**：真金白银12万亿级注资+房价企稳=可以看核心区机会；继续"保交楼"糊弄=房子继续当消费品。
3. 🟢/🔴 **汇率**：人民币破8且管制加码=加速合规出海；企稳=维持节奏。
4. 🟢/🔴 **加税立法**：房产税/遗产税/资本利得税任何一个落地=重估房产和高净值资产，出手要快。
5. 🟢/🔴 **地缘**：台海/关税/脱钩升级=黄金+美元+流动性拉满，权益降仓。

房子少一套，焦虑少一半；杠杆降一分，睡眠好一分；美元多一点，选择多一分。就这么朴素。
